# 六款离线人机游戏

斗地主、掼蛋、麻将、中国象棋、国际象棋、飞行棋进入后即可与电脑对局，无需联网。页面显示自己的身份、当前难度，以及「轮到你操作」或「电脑正在思考」。

| 游戏 | 真人身份 | 电脑玩家 |
| --- | --- | --- |
| 斗地主 | 玩家 1，地主 | 玩家 2、3，两位农民 |
| 掼蛋 | 玩家 1，与玩家 3 组队 | 玩家 3 为电脑队友；玩家 2、4 为电脑对手 |
| 麻将 | 玩家 1 | 其余三位玩家 |
| 中国象棋 | 红方，先行 | 黑方 |
| 国际象棋 | 白方，先行 | 黑方 |
| 飞行棋 | 玩家 1，控制自己的四架飞机 | 其余三组飞机 |

## 操作与回合

- 在游戏设置中选择简单、普通、困难。切换难度会重新开始一局。
- 真人操作结束后，电脑等待约 500 毫秒，再执行一次出牌、过牌、落子或掷骰移动。多个电脑依次操作，思考期间暂停棋盘输入。
- 麻将遇到真人可和牌、吃、碰、杠的机会会等待选择；点击跳过后继续。电脑可自摸，也会判断真人弃牌是否可以和牌。
- 暂停、打开游戏设置、切后台和退出确认都会暂停电脑。关闭设置、取消退出或回前台后，未完成的电脑回合重新等待再执行；手动暂停需手动恢复。
- 悔棋撤回最近一次真人操作及其后电脑应答。重开和改难度取消旧局未执行的应答。
- 对局接续保存待执行的电脑回合与暂停状态；后台接收的对局等应用回前台后继续。接续后不保留原设备的悔棋历史。

## 难度策略

| 游戏 | 简单 | 普通 | 困难 |
| --- | --- | --- | --- |
| 斗地主、掼蛋 | 随机选择合法出牌 | 优先组合与节省大牌，配合队友 | 进一步保留牌组，依据公开剩余张数压制即将出完的对手 |
| 象棋、国际象棋 | 随机选择合法且较安全的落子 | 结合吃子、保护棋子与将军评分 | 比较候选落子和对方应答，处理将杀及失子风险 |
| 麻将 | 随机弃牌 | 优先保留对子、刻子、顺子 | 兼顾搭子与公开弃牌，保留更有价值的组合 |
| 飞行棋 | 随机选择可移动飞机 | 优先推进、起飞和抵达终点 | 兼顾撞机和避开可见的敌方威胁 |

牌类电脑只使用自己的手牌和公开信息，不读取其他玩家的隐藏手牌来决定策略。棋类困难策略限制候选数量，避免无限搜索。

本次完善人机回合与策略，沿用现有单局规则：斗地主固定真人为地主；掼蛋固定级牌 2；麻将不设花牌与番数，吃碰杠的交互仍由真人选择。
