# 界面与交互

## 风格依据

基于 LittleGames 当前源码、2026-10-08 美化及素材记录，以及 2026-10-07 手机截图。后一组截图是前一版本的视觉证据，不是当前最终包验收。本文参数属于用户的应用默认值，不是华为官方强制标准；用于其他工程时服从其设计系统与产品需求。

应用外壳简洁、原生、内容优先；插画使用柔和的小模型质感。系统图标表达通用动作，插画表达具体内容。工具类应用可以只用系统 Symbol，不必复制游戏玩具形象。

## 颜色与表面

| 语义 | 默认实现 | 使用边界 |
| --- | --- | --- |
| 页面背景 | `sys.color.ohos_id_color_sub_background` | 实际颜色由系统主题决定 |
| 主文字 / 次文字 / 辅助文字 | 系统 `text_primary` / `text_secondary` / `text_tertiary` 对应资源 | 重要说明使用次文字层级 |
| 主操作与选中内容 | `sys.color.ohos_id_color_emphasize` | 保持统一系统强调色 |
| 强调底上的文字 | `sys.color.ohos_id_color_text_primary_contrary` | 用于实心主按钮等 |
| 主卡 `surface` | 浅色 `#FFFFFF` / 深色 `#1A1A1A` | 实体内容表面 |
| 次表面 `bg_elevated` | 浅色 `#FFFFFF` / 深色 `#242424` | 内部控件按层级选择 |
| 选中浅底 `selection_surface` | 浅色 `#E8F0FF` / 深色 `#182B49` | 配合强调色文字，避免同色叠加 |
| 内容图标底 `game_icon_background` | 浅色 `#DDEBFA` / 深色 `#24395A` | 为蓝色插画保留辨识度 |
| 分隔线 / 边框 / 遮罩 | 应用语义资源，分别有深浅版本 | 使用既有 `divider`、`border`、`scrim` |

以上十六进制值写入资源，业务页面引用 `$r(...)` 或命名令牌。不要绕过系统资源，直接使用历史 `primary`、`gradient_*` 等资源猜测当前页面配色：当前 `DesignTokens.ets` 的别名可能已指向系统色，部分 `gradient*` 也实际是纯色。

主卡和普通按钮没有重阴影。浮层才使用轻投影；系统悬浮页签使用设备支持的 HDS 材质，支持级别不足时采用官方适配材质，不把全屏内容做成半透明玻璃。

## 页面组织

- 页面壳持有 Navigation / NavPathStack 和导航回调；内容 Tab 接收数据与事件，不承担路由登记或存储读写。
- 顶层目的地数与名称由业务决定。目标 SDK 支持时沿用原生 HDS 悬浮页签；给内容留足导航与安全区空间，使最后一个操作可完整滚动到。
- 多页共享页头，标题、分组标题、卡片及正文的左右边线统一。重要操作留在清楚可达的位置。
- 信息卡依次表达图标、名称、说明、辅助信息。必要时以 `minLines` 等保留稳定文本槽位；缺失辅助信息仍保留布局，避免同一网格高度漂移。实际文本不能假造。
- 分类或筛选横向排列，选中状态同时有颜色和形态/语义表达。搜索与筛选交集有效；改变条件后回顶，同条件和 Tab 往返保持位置。
- 设置按主题、交互、业务、数据分组；组内轻分隔线，值、解释、开关有明确关系。清空记录与恢复偏好是不同动作，清楚说明影响并按实际需求确认。
- 单独处理加载、初始空态、搜索无结果与失败；给出下一步操作。业务失败不应伪装成空列表。
- 弹层共享标题、说明、主次动作和关闭行为；内容可滚动，关键动作保持可达。点击只执行一次，遮罩在退场完成前持续阻断输入。

## 窗口与可访问性

使用当前布局区域或窗口可用宽高，不拿物理屏幕宽度替代可用空间。棋盘/画布同时受宽高限制，先扣除页头、指标、操作栏、安全区与间距。极窄窗口不能用固定最小棋盘撑破容器。

现有 GridRow 使用窗口参考断点 `320vp / 600vp / 840vp`，列数 `4 / 8 / 12`，卡片 span `2 / 2 / 3`，对应紧凑两列和较宽四列。新业务按内容密度调节，不能仅根据设备被声明为 tablet 就固定布局。

给图标按钮设置资源化的 `accessibilityText`，必要时合并卡片可访问性组。读屏需能识别名称、动作和选中状态；关键反馈同时有可见提示，不只靠颜色、声音或震动。检查长标题、英文、空值、极大数字及系统大字体。

## 动效基线

优先复用 `HarmonyMotion` 与资源参数。以下是项目调校值，可按实际交互微调：

| 场景 | 默认参数 |
| --- | --- |
| 卡片 / 按钮按压 | 原生 `clickEffect`，轻级反馈，缩放 0.98 / 0.96 |
| 选中反馈 | `curves.springMotion(0.28, 0.88)`，筛选选中缩放 1.03 |
| 页签选中 | 未选缩放 0.92，选中 1，轻抬升 -1.5vp，字号保持固定 |
| 弹层进入 | 透明度独立渐入，缩放 0.94、纵移 16vp，弹簧参数 0.38 / 0.88 |
| 遮罩 / 内容进入 | 180ms；内容纵移 8vp |
| 弹层退出 | 140ms，缩放 0.98、纵移 8vp |
| 点击保护 | 当前弹层延后业务回调至 320ms；关闭期间禁用动作且保留遮罩 |
| 庆祝 | 一次性、680ms；仅有业务意义时采用 |

弹簧由物理参数决定时长，不同时用固定 `duration` 假定截断效果。用 `this.getUIContext().animateTo(...)` 等上下文 API；由响应式状态驱动 `scale`、`translate`、`opacity`，不逐帧插值 width/height/padding/margin 或整个列表布局。

复杂卡片/浮层设 `renderGroup(true)`。计时器在销毁时清理，回调只提交一次业务操作；数值过渡不能延误实际业务状态。快速点按、取消手势、切页和关闭重开都需验证。

## 素材

通用动作使用系统 Symbol；领域图标保持统一画布、占比、留白、光源、轮廓和投影基线。现有矢量资产和生成器是修改入口，避免引入另一套风格。

玩趣盒内容图标是 120×120 透明 SVG、小模型居中、左上高光，统一蓝/珊瑚/金/薄荷/紫材质。双主题调整纸张、木材、边缘与投影，保留主体辨识度；数字和交互状态优先由 ArkUI 绘制。

图标和对局素材共用 `scripts/game-art-palette.cjs`；图标唯一入口是 `scripts/generate-game-icons.cjs`。改动时生成两套资源，复核缩至实际展示尺寸后的辨识度与透明边缘。素材组合预览不能当作设备画面验收。
