# 玩趣盒单人版本范围调整

日期：2026-10-12。依据开发者确认，当前产品定位调整为单人小游戏合集，从原 100 款目录撤下 11 款，保留 89 款。此文件记录产品范围与桌面验证结果；新版本原生构建、真机复验和上架尚未完成。

当前产品不提供这些游戏的目录、推荐、搜索或启动入口，不再提供同屏多人和局域网房间功能。应用撤下 `ohos.permission.INTERNET` 与 `ohos.permission.GET_NETWORK_INFO`，保留 `ohos.permission.VIBRATE` 用于可关闭的触觉反馈。

撤下游戏的模型、资源与历史资料保留。旧分数、时长和游玩记录继续保存在本机，普通战绩或设置落盘不会删除它们；这些记录不出现在推荐、最近游玩和完整历史，也不计入当前合集的已玩数与时长合计。用户明确执行清空游玩数据时，保留记录一并清空。

系统接续继续由用户主动发起，通过 HarmonyOS 系统能力传递页面和可恢复的本局状态；它不提供联网对局，也不建立开发者账号或云端游戏服务器。

## 文档与验证边界

README 和 `docs/release/` 当前草稿按 89 款单人范围调整。原 100 款的开发、逻辑审计、美术及设备验收记录保持原样，作为对应版本的历史证据；其中的数量、多人能力、网络权限及通过结果不代表本轮单人版本。

2026-10-08 的 22 套、1305/1305 项桌面回归和 e14b3364… 签名包记录属于原 100 款基线。2026-10-09 的运动素材修复也未包含在该基线包中。本轮需重新记录当前源码和资源、构建结果、候选包哈希、实际执行的回归及设备用例，不能沿用历史数字宣称全部通过。

验收重点包括 89 个有效入口、撤下入口不可达、分类数量一致、历史数据展示、保留两款电脑对战、设置与接续，以及最终包不再声明网络权限。已有实机证据仍须按具体包哈希和实际操作范围引用，入口截图不能代替完整通关、全部难度或性能验收。

## 本轮桌面验证

21 套回归共 **1267/1267 项通过**，含 17 项单人目录与撤下边界专项；普通游玩历史 10/10、对局接续 76/76、电脑对手集成 54/54、Collection 67/67、Expansion 330/330，以及规则、完整目标、生成、刷新、设置、时长、窗口和美术检查。部分规则检查继续覆盖保留的已撤下模型，不代表这些玩法仍上架。旧联机 VM 集成及传输套件未纳入本轮产品验证。

静态检查确认应用入口依赖的 122 个 ArkTS 文件不再触达 Lan 模块或 NetworkKit；权限只保留 VIBRATE。基础、简体中文和英文的产品数量、隐私与权限资源已同步。当前执行环境无 DevEco SDK，本轮没有生成新 HAP，也没有执行设备验收。逐套结果、生产文件摘要及验证边界见[验证快照](single-player-validation-2026-10-12.json)。逐套日志保存在 `entry/build/single-player-20261012/`。
