# 应用图标草案 v1

用途：供用户评审的应用图标方案，尚未替换工程中的启动图标。

生成方式：内置 imagegen 图像生成工具，先生成再编辑背景与构图。

文件：`app-icon-concept-v1.png`

## 初始提示词

Use case: logo-brand. Asset type: one finished square application icon for a HarmonyOS casual mini-game collection containing puzzle games and arcade games. Primary request: Create a distinctive, friendly, polished launcher icon that communicates a small collection of fun games and quick relaxation. Subject: a single large compact white game controller emblem, with a bold dark-blue rounded plus directional pad on the left and a neatly arranged 2x2 cluster of four rounded tile buttons on the right, in warm yellow, coral, mint and light blue. The four tiles subtly suggest a collection of puzzle games. Style: premium soft 3D toy-like icon, restrained shallow depth, smooth rounded forms, clean matte surfaces, crisp readable silhouette, professional mobile application branding rather than a detailed illustration. Backdrop: full-bleed rich cobalt-to-sky-blue square background, very subtle gradient, no outer drop shadow, no perspective mockup. Composition: one centered emblem occupying about 65 percent of the canvas, comfortably inside an 18 percent safe margin on every edge, frontal view, balanced proportions, equally suitable for a circular or rounded-square operating-system mask. Soft studio lighting, gentle contact shadow under the emblem only. Constraints: generate the icon artwork itself, square 1024x1024, no text, no letters, no numbers, no watermark, no border, no external logo, no additional objects, no tiny decoration, no glossy chrome, no neon, no collage, do not bake rounded corners into the background.

## 调整提示词

Use case: precise-object-edit. Edit the generated application icon. Preserve the exact white soft-3D game controller design, dark-blue plus directional pad, four pastel rounded tile buttons, palette and friendly visual style. Change only composition and background: shrink the complete controller emblem to 70 percent of the square canvas width and center it in both directions. Fill the ENTIRE square canvas edge to edge with a completely opaque, clean cobalt blue to sky-blue subtle gradient. Every corner must contain solid blue artwork, alpha 255 everywhere. Remove the transparent feathered edge, remove the dark edge vignette, remove any black corners. No rounded outer background mask: the artwork must be a full square and the operating system will apply its own icon mask. Keep generous blue negative space all around the emblem, with the white emblem at least 15 percent away from every canvas edge. One finished app icon only, no text, no watermark, no mockup, no border. Render a crisp square raster application icon.
