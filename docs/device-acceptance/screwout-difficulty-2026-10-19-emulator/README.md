# 拆螺丝难度更新：构建与模拟器验证

当前版本增加真正的板层遮挡、同色三颗回收和槽满失败。简单为 5 板 / 3 色 / 6 槽，普通为 7 板 / 4 色 / 6 槽，困难为 9 板 / 5 色 / 5 槽。困难局会筛去能被固定颜色优先策略直接扫完的布局；所有新局都有合法解法。

Debug、Release 构建成功，457/457 项选定桌面检查通过。其中拆螺丝专项覆盖三档各 100 个局面的完整中间状态、36 个独立几何搜索解法，以及撤销、新旧存档和槽满边界。

当前 Debug 包在 API 26 模拟器 `LittleGamesToyArt` 上完成：

| 实际界面操作 | 结果 |
| --- | --- |
| 普通模式：按界面几何和颜色独立搜索、点击 21 颗螺丝 | 自然胜利，1750 分 |
| 切换困难：搜索并点击 27 颗螺丝 | 自然胜利，2250 分 |
| 困难模式按固定贪心顺序拆解 | 暂存槽 5/5，自然失败 |
| 首步撤销与重放 | 两次胜利流程均通过 |
| 每一步暂存颜色和三颗回收 | 与实际拆下的颜色逐项一致 |
| 重新开局及切换难度 | 颜色、数字刷新且保持三颗守恒，恢复原难度 |

修复了原有嵌套 Builder 接收标量后保留旧颜色的显示问题，改为带响应式参数的螺丝组件。棋盘按可用高度缩放，凹槽与螺丝点击坐标对齐。
