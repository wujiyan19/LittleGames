# 游戏内统一设置

2026-10-03，将 100 款游戏的难度、暂停/继续、重新开始和玩法说明集中到右上角「游戏设置」。新增「页面与应用设置」入口，可打开现有的主题、默认难度、振动反馈、数据管理及关于页面；返回时保留当前对局。数独同时提供重新开始当前题目和新游戏；不支持暂停或难度选择的游戏隐藏相应项目。

15 个游戏视图全部传入游戏 ID 和当前导航栈。原本显示在游戏正文中的玩法卡片及底部说明移入设置，实时玩法的操作按钮仍用于正常游玩。经典玩法补齐 13 份说明，两个合集沿用各自完整规则，base、zh_CN、en_US 三组资源均覆盖全部 100 款。

设置半模态和应用设置页面分别管理可见状态。打开时停止对局计时，关闭后只恢复自动暂停；手动暂停保留，应用回到前台也不能越过仍显示的设置恢复游戏。系统返回在设置/关于页面直接退回上一层，不会触发底层游戏的退出确认。接续校验支持「游戏 → 设置 → 关于」，同时保存被设置覆盖的游戏快照。
