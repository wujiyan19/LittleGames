检查范围是当前规则代码、Collection/Expansion ViewModel、CollectionPage、ExpansionCardBoard 和 ExpansionExtras。没有确认新的规则阻塞问题；此次保留既有规则与输入约束。所有组的游戏 ID 与中文名称见[100 款覆盖表](coverage.md)。

页面核对结果：Collection 的格子读取当前 `vm.state`，选择题键值包含轮次；扑克和麻将按不变的牌 ID 渲染，牌面、选中态和已翻牌状态读取当前快照；飞行棋位置已读取当前状态的 token；纸牌层叠的 itemGenerator 使用 pos，而键值函数未声明 index，按官方规则会在位置改变时重建；不能将它误报成旧位置闭包。家居/纸牌等随机挑战不承诺每个发牌都有必胜解，检查的是既定规则与合法操作通路。

基线已通过 Collection 82、纸牌 AI 29、棋牌 AI 21、扑克 AI 11、电脑对手集成 54 项。Expansion 336 与 completion 190 项另覆盖牌列归位、汉字完整通关、合法提示驱动的完整扑克局、完整飞行棋竞赛及麻将整局等路径。最终统一回归结果见[主报告](README.md)。

以上证据来自实际 ArkTS 模型和 ViewModel 的桌面执行及页面代码审读。真实 ArkUI 字体、触控与动画帧需要设备运行，不能用这些结果替代。
