# 100 款游戏逻辑与画面更新审计

本次检查以 2026-10-08 当前工作树为基线，覆盖 13 款独立游戏、20 款 Collection 游戏、67 款 Expansion 游戏的模型、ViewModel 与页面。保留已有美术、美化及其他未提交改动。

检查内容：合法操作能否达到目标；位置与状态能否进入当前画面；暂停、前后台、重新开始和撤销是否正确；动效与胜负收尾是否一致。桌面脚本执行实际模型与 ViewModel，不模拟 ArkUI 原生绘制。

## 问题汇总与修复顺序

| 优先级 | 已确认问题 | 处理 |
| --- | --- | --- |
| 1：操作与画面一致 | 泡泡龙、落果合成、跑酷、黑洞、大鱼吃小鱼、房间塔防、篮球、节奏落键使用旧棋子快照；餐厅顾客倒计时冻结 | 所有棋子接入现有可观察绘制包装，实时节点读取当前快照；保持稳定身份 |
| 1：操作与画面一致 | 停车后车仍显示、螺丝/板移除不刷新、麻将接龙消除/重排不刷新、解绳节点与边线错位；救援蜜蜂、文字塔防敌人、节拍跳跃角色停在初始位置 | 相应页面使用同一绘制包装，移除、拖动与重排进入当前画面；撤销恢复棋子 |
| 1：格子与操作一致 | 连连看、群消、落槽配对按格子复用却继续显示旧图案；方块拼图槽位消耗/补充后形状陈旧；上车队列/座位和吸色罐数量冻结 | 稳定格子、槽位和颜色索引读取当前状态，更新图案、可操作状态及进度 |

| 2：计时正确 | 扫雷重复隐藏计入暂停时间；每次暂停丢掉不足一秒的时间；退出确认仍计时；结算可能取到上次整秒显示值 | 保留毫秒累计，仅运行时结算；确认期间停表、可见时恢复；终局结算最后区间再计分 |
| 3：终局一致 | 一次切水果同时切到炸弹与最后目标水果时，失败可能被胜利覆盖 | 炸弹失败优先，两个数组顺序均得到相同结果 |
| 3：终局一致 | 大鱼吃小鱼同帧接触大小鱼并达标时，失败被胜利覆盖；成长还会使判定依赖数组顺序 | 当前帧以开始时的体型判定接触与捕食，失败不会被目标达成覆盖 |
| 3：终局一致 | 登山赛车有效接续边界中，冲线覆盖同帧落地失败 | 落地失败优先；正常冲线仍可胜利 |
| 3：方向状态一致 | 大鱼吃小鱼玩家左移时水平速度未更新，画面一直朝右 | 实际水平移动更新朝向，纵移/停止保留最近朝向 |
| 4：对局信息与退出 | 猜数字第 7 次后无法查看早期线索；四款游戏手动暂停后绕过已开启的退出确认 | 猜数字展示全部可滚动记录；暂停对局尊重退出确认设置，取消后保持手动暂停 |
