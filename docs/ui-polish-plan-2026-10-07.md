# 玩趣盒美化实施计划

依据：ClashBox master源码研究、ClashBox 2.1.0与玩趣盒同机实测。用户于2026-10-07授权开始实施。

目标：统一内容表面、页面层级、对齐与间距，使首页/分类/我的/设置更清楚轻盈，保留游戏玩法、记录、导航与设置行为。

| 顺序 | 工作 | 验收 |
| --- | --- | --- |
| 1 | 将主卡片从半透明灰改为独立表面；深色使用中性深灰；区分内部控件与分隔线 | 浅色白卡清楚，深色层级可读，棋盘配色保留 |
| 2 | 三个主Tab共用页头；常规卡片20、小控件12、大横幅24圆角；统一分组与网格间距 | 三页标题、内容边线一致；长文本与时长占位不破坏卡片对齐 |
| 3 | 分类使用单行横向筛选；统一搜索触区；精选/我的整理信息密度和重复留白 | 搜索、分类、空态正常；当前分类可见，历史和设置入口正常 |
| 4 | 设置组内轻分隔线、14fp重要说明、选中颜色统一语义；游戏工具触区44vp | 主题与开关逻辑保留；游戏设置/返回正常 |
| 5 | 游戏设置/结算/退出弹层统一主次表面、圆角、触区；历史/关于/设置宽窗口内容限宽 | 页面进入后风格连贯；弹层动作和记录行为保留 |
| 6 | 同时修复原13款及20款合集老游戏的图标/对局风格差异：共用调色板，重绘角色与材质，补全深色，接入对应页面 | 主体/颜色/材质与当前图标一致，数字与状态清楚，玩法与碰撞保留 |
| 7 | 全部代码完成后集中进行API24构建、必要回归检查、安装手机并检查深浅主题与主导航 | 构建通过，实机截图/布局证据，原设置恢复 |

实施约束：保留既有未提交工作；不复制ClashBox的全局状态结构或手绘浮栏；沿用HDS导航与系统强调色；新增尺寸资源化；不在动画中修改布局尺寸。圆角与间距是玩趣盒提案值，不冒充ClashBox新版实测参数。

本轮优先完成手机主入口与设置的统一。平板继续沿用现有断点网格与系统导航；若未连接平板，将明确标记未实测，不以手机验证代替。

进度：页面美化与追加的老游戏对局美术统一均已完成，已集中构建和检查。新增代码使用现有组件和直接的状态变更，不增加通用兼容或兜底包装；最终手机验收仍待设备连接恢复。
