## 不能用文档代替的材料

软著证书、游戏出版批复、ISBN、APP 备案编号及运营资质均由相应机构或平台核发。本目录只保存真实申报信息和准备材料，不生成或模拟任何证书、批复、编号或已备案状态。

2026-10-10 资料引用国家新闻出版署的[国产网络游戏审批要求](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html)，记录了出版单位、著作权证明或著作权人声明、运营机构等申报条件，以及移动游戏、下载单机游戏相关材料。本轮没有重新核对政策更新，也不据此推定当前 89 款单人合集可一次申报或免审；以平台及主管机关对实际产品的书面要求为准。

2026-10-10 资料引用[工业和信息化部 APP 备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)，记录其针对在中国境内从事互联网信息服务的 APP 主办者，并允许个人作为主办者。当前单人版本的实际功能及系统接续是否落入适用范围，仍需平台或主管部门判断；撤下局域网功能和网络权限不能直接等同于获得豁免。ICP备案与游戏运营 ICP 许可证是不同事项，不可混用。

## 提交顺序

1. 核对个人主体实名认证与 AGC 应用记录，确定该主体能否发布此类游戏。
2. 获取对版号、版权、APP 备案及未成年人保护的书面适用性意见，并按要求办理真实材料。
3. 在 AGC 托管隐私声明，取得真实 HTTPS 地址；补充应用内入口。
4. 完成官方要求的游戏软件包验收，再提交正式上架审核。
