## 可直接使用的应用介绍

玩趣盒是一款 HarmonyOS 原生单人休闲小游戏合集，包含 89 款解谜、棋盘、街机、数字、记忆与反应游戏。中国象棋与国际象棋提供离线电脑对战。支持手机和平板、浅色与深色主题，并在本机保存战绩和游玩记录。应用无需注册账号，不提供联网对局，当前版本不提供应用内购买。

## 隐私声明表单要点

- 本地保存：最高分、累计游玩时长、已玩与最近游玩记录、最近游玩时间、数独和 2048 的未完成对局存档，以及设置和每日推荐批次。
- 网络使用：不提供局域网或互联网联机，不读取本机局域网 IP 地址，不使用开发者云端游戏服务器。
- 系统接续：玩家主动触发时向同账号目标设备传递页面和本局进度。
- 权限：仅保留 `VIBRATE`，撤下 `INTERNET` 与 `GET_NETWORK_INFO`；用途见隐私声明。
- 目前未发现广告、统计、支付、第三方崩溃分析 SDK。最终提交前对签名发布包重新核对。

## 上架前需要确认的三个具体问题

1. 89 款单人小游戏合集，含离线中国象棋与国际象棋电脑对战，适用的游戏出版审批、版号和未成年人保护要求是什么？合集是否需按多款作品分别申报？
2. 个人开发者作为著作权人，是否可直接作为此产品在 AGC 的上架主体；如需有资质的出版单位或运营机构，应如何办理授权和主体关联？
3. 本应用没有互联网游戏服务器、不提供联网对局、不申请网络权限，但保留由系统处理的主动跨设备接续。是否需要办理 APP 备案；如需，个人主体可选择的备案途径及填写的网络资源是什么？

以上问题需从 AGC 游戏上架支持、应用资质审核或主管机关取得书面结论，不能自行宣布豁免。
