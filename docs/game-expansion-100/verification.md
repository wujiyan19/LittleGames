每款均已登记首页分类、搜索、成绩数据和双向路由，附带中英文规则、独立几何 SVG 图标与浅深色资源。首页展示八种不同方向的新增推荐，其余游戏可以在分类页查找。

各规则模块负责各自操作；ExpansionPage 和 ExpansionViewModel 共享标题栏、退出、结算、成绩记录、难度、生命周期与接续。实时游戏使用原有 DisplayFrameLoop，每次物理步长 8 ms，约每 32 ms 更新界面；静止泡泡与已落稳的水果停止帧循环。移动与成长通过 translate/scale 完成。绳结使用 ArkUI Line 绘制，拖动节点使用 translate；拖动时停用父级滚动，松手、取消、后台及退出确认均释放拖动状态。

图片拼图使用项目自绘 SVG 场景，棋盘分别裁出碎片；每款游戏都有独立几何图标，最后 39 款的图标无需字体渲染。旋律记忆使用四个本地生成的 PCM 音符，通过 HarmonyOS SoundPool 播放；加载完成后开放琴键，失败可重试，暂停、后台和退出会停止音符，异步返回的播放句柄也会被停止。平台移动、切水果、越野油门和钓鱼收线均在松手或进入后台时释放按住状态。

## 棋牌与玩法设定

- 斗地主采用一副 54 张牌，玩家固定为地主，对阵两位离线农民，不含叫地主和联网匹配。
- 掼蛋采用两副 108 张牌，固定级牌 2、红桃 2 配牌，玩家与第三位搭档；支持炸弹大小、同花顺、钢板及四王炸弹，按出完名次结算单局，不含多局升级、进贡还贡。
- 麻将为四人 136 张，无花牌、番数及地方规则；支持标准四组加一对、七对、吃、碰、明杠、暗杠和自摸/荣和。电脑主要采用摸打策略，人类玩家可以选择吃碰杠。
- 国际象棋检查将军、自将、易位路经受攻、吃过路兵、四种升变、将死、逼和、重复局面和五十步规则；重复局面和五十步按自动和局处理。中国象棋检查蹩马腿、塞象眼、炮架、九宫和将帅照面。离线电脑为基础对手。
- 蜘蛛纸牌采用单花色 104 张，空当接龙采用 52 张与四空当。飞行棋采用 6 起飞、连掷、同色跳格、碰子和终点回弹的单局规则。
- 体育、射击、经营游戏采用短局目标；一笔画与绳结、节拍跳跃与节奏落键、麻将接龙与四人麻将各自使用不同规则和操作。

## 构建与设备

DevEco Studio 内置 SDK（HarmonyOS 6.1.1 / API 24）的 assembleHap 已通过，最终构建用时 11.969 秒。产物位于 entry/build/default/outputs/default/，包括 entry-default-signed.hap（5,866,160 字节）。本机签名材料保持原有用户配置，不包含在新增源码中。

最终再次执行 hdc list targets 返回 Empty。目前未完成新增 67 款的真机或模拟器画面、触控、字体表现和帧率验收，README 中现有设备照片属于此前版本。设备验收重点是短窗口滚动、多张棋牌与麻将点击、图片裁切、拖动与滚动互斥、双人同时输入、真实音符播放、后台恢复，以及水果/弹幕/塔防长局性能。
