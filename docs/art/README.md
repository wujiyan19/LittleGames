## 视觉设计

沿用应用的蓝色强调色、圆角、轻柔高光与玩具质感。入口采用透明背景的小场景，每款游戏有独立轮廓；进入游戏后沿用同一套材质与棋具。

| 游戏 | 游戏内设计 |
| --- | --- |
| 井字棋 | 陶瓷格板、蓝色叉与珊瑚色圆环 |
| 五子棋 | 木纹棋盘、黑白棋石、交叉网格 |
| 翻转棋 | 玉绿色棋盘、黑白棋石、可落子提示 |
| 落子四连 | 蓝色孔板、蓝色与珊瑚色筹码 |
| 取石子 | 木托盘、随剩余数量变化的蓝色石子 |
| 十字熄灯 | 深蓝灯阵、亮灯与熄灯两种灯泡 |
| 色块归一 | 四色玻璃砖、对应的数字颜色按钮 |
| 迷宫寻路 | 绿篱、石径、蓝色小机器人、绿色出口拱门 |
| 汉诺塔 | 木底座与柱子、五种有编号的彩色圆盘、选中柱描边 |
| 跳子独留 | 木棋盘、凹槽、木质棋钉、选中描边 |

## 来源与维护

本次新增图形均由项目内的几何绘制代码制作，没有复制 GitHub 项目的图片、角色、商标或关卡。素材不依赖外部字体、链接或远程下载。

- `scripts/generate-collection-art.cjs` 是美术源文件：生成 72 个资源名（20 个图标及 52 个游戏内／配套素材），每个资源都有深浅版本，共 144 个 SVG 文件。
- `scripts/expand-catalog.cjs` 调用同一美术生成器，重新生成目录不会覆盖回旧版通用图标。
- `entry/src/main/ets/common/CollectionArt.ets` 管理静态资源选择；`CollectionPage.ets` 按实际游戏状态使用资源。
- `collection-art-manifest.json` 列出资源名、尺寸和游戏对应关系。
- 运行 `node scripts/expand-catalog.cjs` 可重建目录、语言资源及美术；单独更新美术可运行 `node scripts/generate-collection-art.cjs`。
