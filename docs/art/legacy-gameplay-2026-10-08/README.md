# 老游戏图标与对局美术统一

2026-10-08完成。范围为最初13款独立游戏及20款合集游戏，与本轮首页/分类/设置美化合并在同一安装包。

旧图标已升级为柔和玩具式矢量，原对局仍存在像素蛇、旧PNG地鼠、强绿青蛙、深重木棋、较浓卡背等混搭。本轮让图标和两类老游戏生成器共用 `scripts/game-art-palette.cjs`，并重绘原13款的角色、棋具和透明材质覆层。图标主体保留，原13款新增全套深色资源，数字仍由ArkUI绘制。

## 重建

1. `node scripts/generate-collection-art.cjs`：合集素材与统一图标。
2. `node scripts/generate-gameplay-art.mjs`：原13款素材、双主题配色与清单。
3. 提供`sharp`后运行 `node scripts/preview-legacy-gameplay.cjs`、`preview-collection-art.cjs`和`preview-game-icons.cjs`。

最终包位于 `entry/build/default/outputs/default/entry-default-signed.hap`。设备连接恢复后应使用此包统一检查主页导航、原13款深浅入口、动作触区、棋盘状态和公共弹层，结束时恢复原主题。
