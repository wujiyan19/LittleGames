# 局域网双人联机

支持井字棋、五子棋、翻转棋、落子四连、取石子、点格棋和双人拔河。原有同屏玩法仍可直接游玩。

## 使用方法

1. 两台设备连接同一 Wi-Fi，或一台开启热点、另一台连接热点。使用两台设备的热点时，建议由连接热点的设备创建房间，开启热点的设备加入。
2. 两台设备打开同一款游戏，展开「局域网联机」。
3. 一台点击「创建房间」，将显示的房主 IPv4 地址告诉另一位玩家。
4. 另一台输入该地址并点击「加入房间」。连接后开始新对局，房主为玩家一，加入者为玩家二，难度以房主为准。
5. 对局结束后两人都选择再来一局才会重开。离开房间可重新开始本机同屏游戏。

加入仅接受私有 IPv4 地址：`10.*`、`172.16.*` 到 `172.31.*`、`192.168.*`。使用固定 TCP 端口 `41237`，无需账号或远程服务器。若无法连接，请确认连接同一网络、地址正确，且路由器未启用访客网络隔离或客户端隔离。

## 同步与生命周期

房主维护唯一游戏状态；加入者发送操作请求，收到房主确认后更新棋盘。消息包含协议版本、游戏标识、对局编号、状态版本和请求序号。重复请求、错误回合和上一局迟到的操作均不会重复执行。落子类游戏限制当前玩家操作，翻转棋跳过无合法落子的玩家，点格棋完成方格可继续行动；拔河允许同时操作，但每台设备只能控制自己一侧。

TCP 接收按换行分帧，支持拆包与粘包并限制消息大小。两端校验协议与游戏快照，拒绝不同游戏、不同协议或无效消息。握手与失联检测都有超时；断线后冻结联机输入，切后台会主动断开，回前台可重新创建或加入新房间。当前版本不提供断线续局、跨网联机或自动发现房间。联机对局期间无法跨设备接续、单方改难度或悔棋。

`ohos.permission.INTERNET` 用于同一局域网设备间的 TCP 通信，`ohos.permission.GET_NETWORK_INFO` 用于取得房主的局域网地址。

## 验证

- `node scripts/test-lan-multiplayer.cjs`：两个独立游戏实例间的协议、7 款游戏操作同步、回合与角色限制、重复消息、双方重开、异常握手、后台断连和资源覆盖。
- `node scripts/test-lan-transport.cjs`：原生 Socket 调用边界、发送队列、拆包与粘包、UTF-8、超时、取消和资源清理。
- `node scripts/test-collection.cjs`、`node scripts/test-expansion.cjs`、`node scripts/test-continuation.cjs`：原有玩法与接续回归。
- 使用 DevEco Studio 自带 hvigor 进行 API 24 `assembleHap` 编译。
