# 2026-10-13 功能迭代

本轮按用户反馈完善每日精选、每日推荐刷新和画线救援，并完成数独、2048 的本地续玩。当前仍处于功能迭代阶段，产物为 Debug 开发测试包。没有执行商店上传或发布；当前没有连接实体手机。

## 已完成的功能

| 功能 | 当前行为 |
| --- | --- |
| 每日寄语 | 内置 32 条原创祝福，按设备本地日历日期轮换；同一天保持一致，主页安排跨午夜更新。 |
| 每日推荐 | 每批最多六款，点击“换一批”更换；当前 89 款目录中相邻批次全部不同，连续刷新可覆盖整个目录。批次保存在本机，同一天重启后保留，第二天重新开始。 |
| 画线救援 | 绘图区优先接收画线手势，避免被页面滚动夺走；允许完整画出保护圈，保留线长与采样数量上限。画线后才能开始，开始后固定线条；保护十秒通关，可失败、清线及重开。进度显示保护时间，得分根据线长计算。 |
| 数独与 2048 续玩 | 自动保存未完成对局，重新进入时选择“继续对局”或“新开一局”。保存棋盘、难度和本局状态；选择前阻止游戏操作和游玩计时。损坏或不兼容的存档会丢弃并提示。 |
| 数据管理 | 恢复默认设置保留战绩和对局存档；清空游玩数据同时删除战绩及两款游戏存档。已经打开的旧对局不能在清除后重新写回存档。 |

每日内容来自本地资源，不依赖联网服务。扩充寄语时，在 `entry/src/main/ets/model/DailyInspirationCatalog.ets` 末尾追加资源引用，并在 `base`、`zh_CN`、`en_US` 的 `element/string.json` 中补充同名文本。可以持续增加祝福或注明作者的名言；目录长度自动参与轮换。改动后运行 `node scripts/test-daily-featured.cjs` 和原生构建检查。

## 本轮验证

- 桌面回归：24 套、1307/1307 项通过。新增本地存档 20 项、每日精选 11 项、画线救援 9 项。部分历史套件覆盖保留的已撤下游戏模型，不能据此认定这些游戏已恢复到产品目录。
- 原生构建：DevEco Studio 自带 SDK / HarmonyOS 6.1.1（API 24）`assembleHap` 成功，生成当前 Debug 测试包。
- 模拟器：新建独立的 `LittleGames_Features_API24` 手机实例，设备目标 `127.0.0.1:5555`，界面截图尺寸 1256×2760；通过 HDC 的真实点击、滑动、进程关闭及截图验证。保留原有模拟器数据，没有卸载原实例中的应用。
- 数独和 2048：实际操作后关闭应用进程、重新打开，出现续玩选择；选择继续后对比界面中的格子数字和位置，与关闭前一致。
- 每日推荐：实际换批后六款全部变化，今日寄语保持不变；关闭进程重新打开，推荐批次和寄语保留。
- 画线救援：真实画圈过程中页面没有滚动，渲染线段数超过旧采样上限；保护圈通关、进度达到 10/10，重开清线，未保护小狗的线条正常失败。
- 深色界面：复核每日精选、数独续玩弹窗及画线救援首屏的文字、按钮和场景显示；结束后恢复原来的“跟随系统”主题。

模拟器原始操作结果见[检查记录](device-acceptance/features-2026-10-13-v3/features.json)，截图与布局保存在相同目录。`v2` 等较早目录为修复过程证据，绑定各自的包哈希。

自动界面检查入口为 `scripts/device-feature-iteration.cjs`，可分别使用 `daily`、`rescue`、`saves` 和 `appearance` 参数。通过 `LITTLEGAMES_ART_TARGET` 指定 HDC 目标，通过 `LITTLEGAMES_ART_OUTPUT` 指定证据目录。安装的新包若改变哈希，应使用新的证据目录；脚本只操作已渲染的界面，不向应用注入棋盘或对局状态。

当前签名测试包 SHA-256：`76532c18a7927bdf35c020e4467d7df110a3d8a9e0c0bd49a4082844aab84272`。输出为 `entry/build/default/outputs/default/entry-default-signed.hap`；签名、证书和口令不写入报告。

构建日志位于 `entry/build/iteration-20261013/native-build.log`；全量回归入口为 `scripts/run-regressions.cjs`，各套件日志及结果位于 `entry/build/iteration-20261013/regressions/`。构建目录被 Git 忽略，保留的验证快照见同目录下的 `feature-iteration-verification-2026-10-13.json`。

回归执行中曾出现一次旧 Node/V8 解析器进程异常；相关套件单独重跑与完整重跑均通过。设备脚本曾误点被底部导航栏遮挡的卡片、因首页滚动位置误判页面，以及向错误方向寻找分类标签；已修正为依据实际可点击区域、当前页面及目标标签方向判断。失败尝试保留在原始记录中，后续成功检查标记解决时间。
